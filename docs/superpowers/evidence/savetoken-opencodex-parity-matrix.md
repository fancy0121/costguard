## How to read this matrix

- `upstream_static_status` describes whether the upstream source path and a focused test path were found by static inspection. It does not claim that the test was executed.
- `parity_status` describes the current SaveToken workspace. The workspace contains the contract and audit plan, but no SaveToken runtime `src/` or test owner outside the read-only upstream clone. Therefore no upstream capability is claimed as implemented by SaveToken.
- Allowed statuses in both status columns are exactly: `PRESENT`, `MISSING`, `PARTIAL`, `NOT_TESTED`, `UNKNOWN`.
- `Evidence hash ref` points to the full manifest hash above. The exact source and test paths in each row are the primary traceability evidence.
- `NOT_TESTED` is the execution result for this task globally: no upstream dependency installation, typecheck, or test suite was run. Static test-file presence is not a test result.
- No API keys, OAuth state, cookies, tokens, private configuration, or real user data were read into this artifact.
